# Asymmetric-based hybrid area

Reference-style family area for the assignment's RSA-3072-OAEP,
X25519-HKDF-SHA-256, and RFC 7919 FFDHE3072-HKDF-SHA-256 workflows.

The current runnable implementation remains in the project root. The exact
assignment configurations, common AES-GCM envelope, and RFC group parameters
are not replaced by the dat-nix repository's different scheme set.
