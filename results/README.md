# Results area

This directory mirrors the reference repository's family and RQ organization:

~~~text
results/
  hashing/{rq1,rq2,rq3}/{runs,analysis}/
  symmetric/{rq1,rq2,rq3}/{runs,analysis}/
  asymmetric/{rq1,rq2,rq3}/{runs,analysis}/
~~~

Existing phase-2 outputs under data/runs and data/analysis are preserved. New
full-run outputs may be placed in this structure when the next collection
phase begins.
